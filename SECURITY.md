# Security policy

This plugin reads images the app gives it and returns the text in them. If you find a way to make it read a file the app did not ask for, to crash the app with a crafted image, or to send anything off the device, please tell us privately first.

## Reporting a vulnerability

**Do not open a public issue.** Use GitHub's private reporting: the **Security** tab of this repository, then **Report a vulnerability**. Only the maintainers see the report.

Please include what an attacker can do and what they need first, the steps to reproduce it, the version of the plugin and the Android version, and anything you already know about a fix.

This project is maintained in spare time. You will get an answer within 7 days, and you will be credited in the changelog unless you prefer otherwise.

## Supported versions

Only the latest release gets security fixes.

## Out of scope

Problems in ML Kit or Google Play Services themselves: report them to Google.
